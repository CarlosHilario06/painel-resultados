# Painel de Resultados

Dashboard estático (HTML/CSS/JS puro, sem build) que lê CSVs exportados do Google Sheets
e registra snapshots de Gasto/Retorno/Lucro/% por horário, com ranking de campanhas por país.

## Rodar localmente
Só abrir o `index.html` no navegador.

## Publicar no GitHub Pages
1. Settings > Pages > Branch: `main` / pasta `/ (root)` > Save
2. O site fica em `https://SEU_USUARIO.github.io/NOME_DO_REPO/`
